Desktop Frames + — personal build

A fork of limbo666/DesktopFramesPlus, kept by vittop89.

Desktop Frames + gathers desktop icons into frames. This is a personal build of that program, carrying a few fixes and an Agenda plugin that shows a Google calendar inside a frame.

These pages exist for one reason: Google requires a home page and a privacy policy at public addresses before an OAuth application can be taken out of testing. There is nothing to download here.
